# mobile-storage
# 实验二：数据持久化
## 实验目标
掌握SharedPreferences、SQLite数据库和Room框架的使用。
## 实验要求
1. 使用SharedPreferences存储用户设置（主题/语言/字体大小）
2. 使用SQLiteOpenHelper创建数据库并实现CRUD操作
3. 使用Room框架重构SQLite操作（DAO/Entity/Database）
4. 实现数据导入导出（JSON格式）
5. 实现搜索功能（使用SQL LIKE查询）
6. 对比三种存储方式的适用场景并撰写说明
## 评分标准
| 项目 | 分值 |
|------|------|
| SharedPreferences | 15% |
| SQLite | 25% |
| Room框架 | 30% |
| 数据导入导出 | 20% |
| 场景分析 | 10% |
